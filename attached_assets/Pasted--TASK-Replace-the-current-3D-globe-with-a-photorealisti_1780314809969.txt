## Step 2 — Create the EarthGlobe component

Create src/components/EarthGlobe.tsx with these exact specs:

Geometry:
- SphereGeometry with 128 width segments and 128 height segments (smooth)
- Radius: 2.4 units

Textures (load from public CDN — use these exact URLs):
- Day map:     https://unpkg.com/three-globe/example/img/earth-day.jpg
- Bump map:    https://unpkg.com/three-globe/example/img/earth-topology.png
- Specular:    https://unpkg.com/three-globe/example/img/earth-water.png
- Night map:   https://unpkg.com/three-globe/example/img/earth-night.jpg
- Clouds:      https://unpkg.com/three-globe/example/img/earth-clouds.png

Material — MeshPhongMaterial:
- map: day texture
- bumpMap: topology texture, bumpScale: 0.08
- specularMap: water texture, specular: new THREE.Color(0x333333), shininess: 25
- The material should look glossy on oceans, matte on land

Atmosphere glow layer (separate mesh, slightly larger sphere):
- Use MeshPhongMaterial with transparent: true, opacity: 0.08
- Color: #4fc3f7 (light blue)
- Side: THREE.FrontSide
- Scale: 1.02 relative to earth sphere

Cloud layer (separate mesh):
- Slightly larger than earth (scale 1.01)
- MeshPhongMaterial with alphaMap: clouds texture
- transparent: true, opacity: 0.4, depthWrite: false
- Rotate clouds 20% slower than earth (independent rotation)

Lighting:
- AmbientLight: intensity 0.15 (keeps night side visible but dark)
- DirectionalLight: color #fff8e7 (warm sunlight), intensity 1.4,
  position: [-5, 3, 5] (sun from upper-left — India/Asia visible on right side)
- Add a subtle blue PointLight at position [10, -5, -10] intensity 0.1
  to simulate earthshine on the night side

Rotation:
- Auto-rotate: y += 0.0008 per frame (slow, majestic)
- On mouse hover over canvas: pause auto-rotate, enable OrbitControls drag
- On mouse leave: resume auto-rotate, disable drag
- Initial rotation: set y-rotation so Asia/India is prominently visible
  (approximately y: -0.5 radians)

Canvas setup (in parent component):
- camera position: [0, 0, 6], fov: 45
- alpha: true (transparent canvas background — blends with cream site bg)
- antialias: true
- Add fog: THREE.Fog('#f5f0e8', 10, 30) — very subtle, matches site bg color
