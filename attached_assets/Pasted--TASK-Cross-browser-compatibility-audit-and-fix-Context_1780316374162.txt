# TASK: Cross-browser compatibility audit and fix

## Context
React + Vite site. Must work correctly in:
- Chrome 120+ (primary)
- Firefox 120+
- Safari 16+ (macOS + iOS)
- Edge 120+

# Fix every issue found. Output complete modified files.
# Do NOT document issues without providing the fix.

## Three.js / WebGL (Globe component)

[ ] Test WebGL support: if !window.WebGLRenderingContext, show fallback image.
    Safari on older iOS has WebGL quirks — test canvas alpha transparency.
[ ] Safari: -webkit- prefixes may be needed for some canvas CSS properties.
[ ] Firefox: verify OrbitControls mouse events fire correctly.
[ ] Fix for Safari on iOS: add touch-action: none on the canvas element
    to prevent default iOS scroll interfering with globe drag.

## CSS rendering differences

[ ] Fonts: add -webkit-font-smoothing: antialiased and
    -moz-osx-font-smoothing: grayscale to the root CSS.
    Without this, fonts look heavier on macOS Safari/Firefox.

[ ] Flexbox gap: verify gap in flex containers works in all targets.
    Safari 14 and below don't support flex gap — replace with margin if needed.
    Since target is Safari 16+, this should be fine but verify.

[ ] CSS Grid: verify all grid layouts render consistently.
    If any grid uses subgrid, note that Firefox supports it but Chrome added
    it later — ensure fallbacks exist.

[ ] Clip-path (globe circular frame): verify the circular clip renders
    correctly in Firefox and Safari. Firefox sometimes needs
    -webkit-clip-path as well as clip-path.

[ ] CSS custom properties (variables): all browsers in scope support them,
    but verify none are missing fallbacks for critical layout values.

[ ] Scroll behavior: scroll-behavior: smooth is not supported in Safari
    versions before 15.4. Use a JS polyfill or @supports check.

## JavaScript / React

[ ] Optional chaining (?.) and nullish coalescing (??): supported in all
    target browsers. Verify Vite build transpiles for targets correctly.
    Add to vite.config.ts: build: { target: ['chrome90', 'firefox90', 'safari15', 'edge90'] }

[ ] IntersectionObserver (used for pausing globe animation): supported in all
    targets, but add a guard: if ('IntersectionObserver' in window)

[ ] ResizeObserver (if used for responsive canvas): same guard pattern.

[ ] requestAnimationFrame: universal — no fix needed.

[ ] window.matchMedia for prefers-reduced-motion: supported in all targets.
    Add check before starting shooting star animation:
    const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches
    If true: skip shooting stars and globe auto-rotate entirely.

## Form inputs (Login/Register/Consultation forms)

[ ] Safari: date inputs (type="date") render differently. If used, add a
    consistent custom date picker or style the native one with CSS.
[ ] Firefox: type="number" shows spinner arrows — hide with CSS if unwanted:
    input[type=number]::-moz-appearance: textfield
[ ] All browsers: ensure autocomplete attributes are set correctly on
    email/password fields to trigger native browser autofill.
[ ] Password fields: verify show/hide toggle works in all browsers
    (Edge has a built-in eye icon that may conflict with custom one).
    Hide Edge's default: input[type=password]::-ms-reveal { display: none }
