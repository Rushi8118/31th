## **Prompt: Complete UI/UX Audit, Responsiveness & Accessibility Overhaul**

**Project Context:**  
You are auditing and fixing the **Admin Panel** (and its connected public-facing components) for a visa consultancy platform similar to the Siddhivinayak Overseas design system shown in the reference image. The interface uses a cream/off-white background (`#F9F7F2`), deep navy text (`#1A1A2E`), gold/yellow accents (`#C9A227`), rounded buttons, data cards, and a 3D globe visualization.

---

### **1. Responsive Breakpoint Audit (320px, 768px, 1024px, 1440px)**

**Task:** Test the admin panel on **four specific breakpoints** and document every failure.

**Checklist per breakpoint:**
- **320px (Mobile Small):** Check sidebar collapse, table horizontal scroll, card stacking, button touch targets (min 44×44px), font scaling, modal full-screen behavior, form input widths, globe visualization fallback.
- **768px (Tablet):** Check 2-column grid collapse, navigation hamburger menu functionality, dropdown positioning, chart resizing, padding/margin compression, sticky header behavior.
- **1024px (Laptop):** Check sidebar expanded vs. icon-only mode, table column truncation, tooltip positioning, split-pane layouts, dashboard widget reflow.
- **1440px (Desktop):** Check max-width container constraints, excessive whitespace, ultra-wide table stretching, alignment of stat cards (like "98% visa success rate", "10+ countries served"), 3D element rendering boundaries.

**Deliverable:**  
A numbered list of **every element that breaks, overflows, or becomes unusable**, with:
- Screenshot description
- CSS selector / component name
- Exact viewport width where it fails
- Severity (Critical / Major / Minor)
- Proposed fix (code snippet or architectural change)

**Then fix each one.** Ensure no horizontal scrollbars appear below 1024px unless for data tables with intentional `overflow-x: auto`.

---

### **2. Keyboard Navigation & Screen Reader Accessibility**

**Task:** Make **all interactive elements** fully operable without a mouse and compatible with NVDA/JAWS/VoiceOver.

**Elements to test:**
- **Buttons:** "Start Your Visa Journey", "Free Consultation", "Login", "Register", action buttons in tables
- **Dropdowns:** Country selectors, visa type filters, user profile menu
- **Modals:** "Free Consultation" form, confirmation dialogs, detail views
- **Tables:** Sortable headers, pagination controls, row action menus, checkbox selection
- **Navigation:** Main nav, sidebar menu, breadcrumb trails, skip-to-content link

**Keyboard requirements:**
- Logical `Tab` order that follows visual hierarchy (no tab traps)
- `Enter` / `Space` activation for all buttons and links
- `Escape` closes modals, dropdowns, and sidebars
- `Arrow keys` navigate dropdown options and table cells (where applicable)
- Visible `:focus` rings (custom styled, not browser default, using `outline: 2px solid #C9A227; outline-offset: 2px;`)
- `Shift + Tab` reverse navigation works correctly

**Screen reader requirements:**
- Add descriptive `aria-label` to icon-only buttons (e.g., "Edit application", "Delete user")
- Use `aria-expanded` on dropdown toggles
- Use `aria-modal="true"` and `role="dialog"` on modals with `aria-labelledby` pointing to modal title
- Tables need `scope="col"` / `scope="row"` and captions via `aria-label` or `<caption>`
- Live regions (`aria-live="polite"`) for success/error toast notifications
- Globe visualization needs `role="img"` with descriptive `aria-label` (e.g., "3D visualization showing countries served") or a text fallback
- Form inputs need associated `<label>` elements (not just placeholders) and `aria-describedby` for error messages

**Deliverable:**  
- ARIA audit report listing every missing label, incorrect role, or broken focus flow
- Before/after code snippets for each fix
- Test recording notes (Tab path through entire page)

### **3. Cross-Browser Compatibility Test**

**Task:** Test on **Chrome (latest), Firefox (latest), Safari (latest macOS + iOS), Edge (latest)**.

**Test areas:**
- **Rendering:** Fonts (especially the serif/sans-serif mix in headings), border-radius consistency, box-shadow rendering, gradient fidelity on gold accent buttons, backdrop-filter on glassmorphism cards (like the "8–12 weeks" timeline badge)
- **Layout:** Flexbox/Grid gaps, sidebar positioning, sticky footer behavior, table column widths
- **Functionality:** JavaScript event handling on custom dropdowns, modal focus trapping, chart.js or D3.js rendering, date pickers, file upload drag-and-drop
- **Performance:** 3D globe WebGL fallback to static image on Safari if needed, animation frame rates

**Console audit:**
- Document **every JS error, warning, or deprecation notice** per browser
- Check for `ResizeObserver loop limit exceeded` errors during responsive testing
- Verify no CORS issues on API calls

**Deliverable:**  
- Cross-browser matrix (Pass/Partial/Fail per browser per feature)
- List of rendering differences with screenshots
- JS console error log with stack traces
- Browser-specific CSS fixes (e.g., `-webkit-appearance`, `@supports` queries) or polyfills applied

### **4. Hover Animation & UI/UX Quality Improvements**

**Task:** Elevate the interaction design to match premium consultancy standards.

**Hover animation requirements:**
- **Buttons:** 
  - Primary (gold): `transform: translateY(-2px); box-shadow: 0 4px 12px rgba(201, 162, 39, 0.3); transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);`
  - Secondary (outlined): Fill background with `background-size: 200% auto; background-position: right center;` sweep effect
  - Arrow icons inside buttons: `transform: translateX(4px);` on hover
- **Cards/Stats:** Subtle lift (`translateY(-4px)`) with soft shadow expansion, `transition: 0.3s ease`
- **Navigation links:** Underline grows from center using `transform: scaleX(0)` → `scaleX(1)` with `transform-origin: center`
- **Table rows:** `background-color` fade transition (`0.15s`) on hover, not instant jump
- **Globe/3D elements:** Gentle rotation pause on hover, or tooltip fade-in with `opacity 0→1` and `translateY(10px)→0`
- **Badges/Pills:** Slight scale (`1.05`) with gold glow

**UX micro-improvements:**
- Add **skeleton screens** for dashboard data loading instead of spinners
- Implement **toast notifications** for admin actions (success/error) with auto-dismiss and manual close
- Add **empty states** for tables with illustrations and CTA buttons
- Ensure **loading states** on all async buttons (spinner inside button, disabled state)
- Add **breadcrumb navigation** in admin panel for deep pages
- Implement **sticky table headers** when scrolling through visa application lists
- Add **confirmation modals** for destructive actions (delete, reject application)
- Use **tooltips** for truncated table text (hover to see full content)

**Deliverable:**  
- CSS/SCSS file with all hover animations using `transform` and `opacity` only (GPU-accelerated)
- Animation timing tokens documented (`--transition-fast: 150ms`, `--transition-base: 250ms`, `--transition-slow: 350ms`)
- Before/after video description of interaction feel
- List of all UX pain points resolved
